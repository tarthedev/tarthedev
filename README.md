# Rollinson Network: Stripe integration

A Cloudflare Worker that handles billing for Rollinson Network clients:

1. **Build fee (Invoicing + Payments).** After a client approves their free preview, you call
   `POST /admin/invoice`. The Worker emails them a Stripe-hosted invoice ($1,200 intro or $2,000
   standard, due in 7 days).
2. **Care plan (Billing).** If `care_plan` is `true`, the card the client pays with is saved.
   When the invoice is paid, the Worker starts the $129/month plan on that card. The first charge
   is 30 days after payment (`CARE_PLAN_DELAY_DAYS`).
3. **Tax.** Products carry Stripe Tax codes: Website Design `txcd_10701200` for the build and
   Website Hosting `txcd_10701100` for the care plan. Set `AUTOMATIC_TAX` to `"true"` once Stripe
   Tax is set up (see below).
4. **In person (Terminal).** Use Tap to Pay in the Stripe Dashboard mobile app. No code needed.

This follows the plan generated by Stripe's `stripe_implementation_planner`: hosted invoices,
Smart Retries, the no-code customer portal, Stripe Tax, and Dashboard Tap to Pay.

## Endpoints

| Route | Who calls it | What it does |
| --- | --- | --- |
| `POST /admin/invoice` | You (`Authorization: Bearer $ADMIN_TOKEN`) | Creates or updates the customer, creates the build invoice, and emails it |
| `POST /webhook` | Stripe | Verifies the signature; on `invoice.paid` starts the care plan (safe to retry) |

Example:

```sh
curl -X POST https://<your-worker>/admin/invoice \
  -H "Authorization: Bearer $ADMIN_TOKEN" -H 'content-type: application/json' \
  -d '{"name":"DWRG Heating & Cooling","email":"owner@example.com","phone":"+12525550100",
       "address":{"line1":"100 Main St","city":"Elizabeth City","state":"NC","postal_code":"27909"},
       "build":"intro","care_plan":true}'
```

The response includes `hosted_invoice_url`. Stripe also emails the invoice to the client.

## Setup

```sh
npm install
cp .dev.vars.example .dev.vars        # fill in your keys
npm run setup:stripe                  # creates products/prices (safe to re-run)
npm run dev                           # local Worker on :8787
stripe listen --forward-to localhost:8787/webhook   # prints the whsec_ for .dev.vars
```

Deploy:

```sh
npx wrangler secret put STRIPE_SECRET_KEY
npx wrangler secret put STRIPE_WEBHOOK_SECRET
npx wrangler secret put ADMIN_TOKEN
npm run deploy
```

Then in the Stripe Dashboard, under Developers > Webhooks, add `https://<your-worker>/webhook`
with the events `invoice.paid`, `invoice.payment_failed`, and `customer.subscription.deleted`.

## Dashboard settings (one-time, no code)

- **Stripe Tax:** Settings > Tax. Add your head office address and NC registration, then set
  `AUTOMATIC_TAX` to `"true"` in `wrangler.jsonc`.
- **Branding:** Settings > Branding. Add your logo and colors (shown on invoices and receipts).
- **Customer portal:** Settings > Billing > Customer portal. Allow cancel and payment-method
  updates, and turn on the no-code login link so clients can manage the care plan themselves.
- **Failed payments:** Settings > Billing > Revenue recovery. Turn on Smart Retries and the
  failed-payment emails.
- **Tap to Pay:** Install the Stripe Dashboard app on your phone to take in-person payments.
